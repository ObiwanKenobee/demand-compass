# 🌐 Atlas Sanctum — Marketing North Star Dashboard

> **Measure institutional demand, not vanity traffic.**

The Atlas Sanctum Marketing North Star Dashboard is an enterprise demand-intelligence interface for understanding whether the Atlas Sanctum ecosystem is gaining meaningful adoption among the institutions it is designed to serve.

This is not a conventional marketing dashboard.

It does not optimize around:

* Page views
* Impressions
* Followers
* Likes
* Random traffic spikes

Those metrics can be useful as supporting signals, but they are not the destination.

Atlas Sanctum is enterprise-driven.

Its ecosystem is intended to serve and engage:

* Governments
* Climate funds
* Enterprises
* Research institutions
* Development organizations
* Universities
* Strategic technology partners

Therefore the dashboard revolves around a harder question:

> **Are serious organizations entering the Atlas Sanctum ecosystem?**

---

# ⭐ North Star Metric

## Qualified Institutional Demand

**Qualified Institutional Leads (QIL)** represent organizations that have moved beyond passive awareness and entered a meaningful commercial, research, policy, or implementation conversation with Atlas Sanctum.

Examples include:

* Climate funds requesting a demonstration
* Governments exploring policy simulations
* Enterprises requesting regenerative verification
* Research institutions proposing collaboration
* Organizations requesting pilot programs
* Institutions evaluating an API or data integration

# 🧭 Design Philosophy

## One North Star

All supporting metrics should explain movement toward qualified institutional demand.

## Signal Over Noise

Display fewer metrics, but make each one actionable.

## Depth Over Reach

An institution requesting a pilot is more strategically meaningful than thousands of anonymous impressions.

## Context Over Vanity

A number should explain what changed and why.

## Demand Over Attention

The dashboard measures **institutional intent**, not merely audience size.

## Calm Over Hype

The visual system should communicate confidence and clarity rather than constant urgency.

> **The dashboard should make the important things obvious.**

# 📈 Attribution

The dashboard should support multiple attribution views.

### First Touch

Where the organization first encountered Atlas.

### Latest Touch

The most recent meaningful interaction.

### Multi-Touch

Multiple events contributed to eventual qualification.

### Strategic Source

Relationship-driven opportunities such as partnerships and institutional introductions.

The system should avoid pretending attribution is perfectly causal.

Attribution is a model of influence, not proof that a single marketing action created an institutional decision.

---

# 🛡 Data Integrity

Because the North Star drives organizational decisions, measurement quality matters.

Every major metric should carry:

```json
{
  "value": 47,
  "period": "2026-10",
  "definition": "Qualified institutional organizations",
  "source": "crm",
  "last_updated": "2026-10-01T12:00:00Z"
}
```

This keeps the dashboard auditable.
